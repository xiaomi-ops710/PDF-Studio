# PDF Studio

iPad向けPDFビューアPWA（Material 3 Expressive）。

## 初回セットアップ（1回だけ）
1. GitHubで新しいリポジトリを作成
2. Settings → Pages → **Source を「GitHub Actions」** にする
3. Settings → Actions → General → Workflow permissions を **Read and write permissions** にする
4. リポジトリで「Add file → Create new file」を開き、ファイル名に `.github/workflows/deploy.yml` と入力して、同梱の `deploy.yml` の中身を貼り付けてコミット
   （`.github` は隠しフォルダのため、アップロードではなく新規作成で入力するのが確実です）

## 更新・デプロイ（毎回）
`pdf-studio.zip` を「Add file → Upload files」でリポジトリ直下にアップロードしてコミットするだけです。
Actionsが自動でZipを展開（フォルダ1つに包まれている場合は中身を直下へ）→ Zipを削除 → Pagesへ公開します。
公開URLをiPadのSafariで開き、共有 → ホーム画面に追加。

## 主な機能
- ホーム: 最近のファイル（サムネイル・続きから読む・検索・並べ替え）
- 書き込み: ペン（筆圧）/蛍光ペン/図形（線・矢印・四角・楕円）/消しゴム/テキストボックス
- ドキュメント編集: ページの回転・並べ替え・複製・削除・白紙追加・他のPDF/画像の挿入・選択ページの書き出し
- 設定: テーマカラー（自由に選択）・ライト/ダーク・表示の初期設定・筆圧の強さ・データ管理

## Acrobat風の画面構成
- ホーム: クイック操作のタイル、最近のファイル/スター付き、下部ナビ（ホーム・ファイル・検索・ツール）、右下の＋
- 文書画面: 上部に「編集・書き出し・入力と署名・その他のツール」、左に縦のツール列、右にコメント/ページ一覧とページ送り、「…」に詳細メニュー（表示設定・読み上げ・圧縮・結合・印刷など）

## 機能
- コメント: テキストのハイライト・下線・取り消し線（文字を選択すると自動で付く）、付箋、手描きペン（筆圧）、蛍光ペン、図形、テキスト
- 入力と署名: 署名（保存して再利用）、チェック・バツ・丸、今日の日付、スタンプ、画像の追加
- ツール: ページを整理、PDFを結合、PDFを分割、圧縮、画像・テキストとして書き出し、カメラでスキャン、詳細情報
- サイドバー: ページ一覧 / しおり / 検索 / コメント一覧、見開き表示（設定）

## ペン・ツールの細かな設定
- ペン: 種類（ボール/万年筆/筆/鉛筆）、太さ（0.5〜30pt）、不透明度、筆圧の強さと筆圧カーブ、手ぶれ補正、実線/破線/点線、色（最近使った色・カスタム色）、お気に入り3枠
- 図形: 直線・矢印・両矢印・四角・角丸・楕円・三角、塗りつぶし、線種
- テキスト: フォント（ゴシック/明朝/丸ゴ/等幅）、太字・斜体、背景色、複製
- 消しゴムは線・図形・テキスト・画像すべてに効きます
- マイしおり、ページの色調（セピア/モノクロ/反転）、検索結果のハイライト

## 追加した10機能
1. ノート作成（白紙・罫線・方眼・ドット）／2. 自動スクロール（速さ調整）／3. 書き込みの表示・非表示／4. ページを1枚ずつ止めるスナップ（設定）／5. 画面端タップでページ送り（設定）／6. 透かし追加／7. ページ番号追加／8. 詳細情報（タイトル・作成者など）の編集／9. テキストスタンプとイニシャル署名／10. コメント（ハイライトした文章を含む）の書き出し

- 機能: 線のタップで削除・複製・色/太さ変更、ズームのプリセット、「…」から最近のファイルへ切替、起動時に前回のファイルを開く、書き込みのバックアップと復元、使い方ガイド、キーボードショートカット

## 補足
- アイコンはGoogle FontsのMaterial Symbols（Rounded）を読み込みます。初回はオンラインで開いてください。
- 更新を確実に配信するときは sw.js の `V`（キャッシュ名）を変更してください。
- PDF描画ライブラリ(pdf.js / pdf-lib)はcdnjsから読み込み、初回以降はService Workerがキャッシュします。
- 書き込みと開いたファイルは端末内(IndexedDB)に保存されます。
