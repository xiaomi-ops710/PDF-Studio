# PDF Studio

iPad向けPDFビューアPWA（Material 3 Expressive）。

## 初回セットアップ（1回だけ）
1. GitHubで新しいリポジトリを作成
2. Settings → Pages → **Source を「GitHub Actions」** にする
3. Settings → Actions → General → Workflow permissions を **Read and write permissions** にする
4. リポジトリで「Add file → Create new file」を開き、ファイル名に `.github/workflows/deploy.yml` と入力して、同梱の `deploy.yml` の中身を貼り付けてコミット
   （`.github` は隠しフォルダのため、アップロードではなく新規作成で入力するのが確実です）

## 更新・デプロイ（毎回）
`pdf-studio.zip` を「Add file → Upload files」でリポジトリ直下にアップロードしてコミットするだけです。
Actionsが自動でZipを展開（フォルダ1つに包まれている場合は中身を直下へ）→ Zipを削除 → Pagesへ公開します。
公開URLをiPadのSafariで開き、共有 → ホーム画面に追加。

## 主な機能
- ホーム: 最近のファイル（サムネイル・続きから読む・検索・並べ替え）
- 書き込み: ペン（筆圧）/蛍光ペン/図形（線・矢印・四角・楕円）/消しゴム/テキストボックス
- ドキュメント編集: ページの回転・並べ替え・複製・削除・白紙追加・他のPDF/画像の挿入・選択ページの書き出し
- 設定: テーマカラー（自由に選択）・ライト/ダーク・表示の初期設定・筆圧の強さ・データ管理

## Acrobat風の画面構成
- ホーム: クイック操作のタイル、最近のファイル/スター付き、下部ナビ（ホーム・ファイル・検索・ツール）、右下の＋
- 文書画面: 上部に「編集・書き出し・入力と署名・その他のツール」、左に縦のツール列、右にコメント/ページ一覧とページ送り、「…」に詳細メニュー（表示設定・読み上げ・圧縮・結合・印刷など）

## 機能
- コメント: テキストのハイライト・下線・取り消し線（文字を選択すると自動で付く）、付箋、手描きペン（筆圧）、蛍光ペン、図形、テキスト
- 入力と署名: 署名（保存して再利用）、チェック・バツ・丸、今日の日付、スタンプ、画像の追加
- ツール: ページを整理、PDFを結合、PDFを分割、圧縮、画像・テキストとして書き出し、カメラでスキャン、詳細情報
- サイドバー: ページ一覧 / しおり / 検索 / コメント一覧、見開き表示（設定）

## ペン・ツールの細かな設定
- ペン: 種類（ボール/万年筆/筆/鉛筆）、太さ（0.5〜30pt）、不透明度、筆圧の強さと筆圧カーブ、手ぶれ補正、実線/破線/点線、色（最近使った色・カスタム色）、お気に入り3枠
- 図形: 直線・矢印・両矢印・四角・角丸・楕円・三角、塗りつぶし、線種
- テキスト: フォント（ゴシック/明朝/丸ゴ/等幅）、太字・斜体、背景色、複製
- 消しゴムは線・図形・テキスト・画像すべてに効きます
- マイしおり、ページの色調（セピア/モノクロ/反転）、検索結果のハイライト

## 追加した10機能
1. ノート作成（白紙・罫線・方眼・ドット）／2. 自動スクロール（速さ調整）／3. 書き込みの表示・非表示／4. ページを1枚ずつ止めるスナップ（設定）／5. 画面端タップでページ送り（設定）／6. 透かし追加／7. ページ番号追加／8. 詳細情報（タイトル・作成者など）の編集／9. テキストスタンプとイニシャル署名／10. コメント（ハイライトした文章を含む）の書き出し

## v9 の追加
- 画面: 上部バーのスクロール自動非表示、読書進捗バー、ページ用スライダー、ペン設定のコンパクトバー（「詳細」で全設定）、ホームの「続きから読む」カード、ファイル一覧のリスト/グリッド切替、ページ読み込み中の表示、ツール検索
- 機能: 線のタップで削除・複製・色/太さ変更、ズームのプリセット、「…」から最近のファイルへ切替、起動時に前回のファイルを開く、書き込みのバックアップと復元、使い方ガイド、キーボードショートカット

## v10: iOS風マークアップツールバー
- 左から 選択・元に戻す・やり直し／ペン・ボールペン・蛍光ペン・消しゴム・鉛筆・定規／色（5色＋カスタム）／投げ縄・追加(＋)・その他(…)
- 上のハンドルをドラッグすると、ツールバーを上下左右の端にスナップして移動できます（設定でも変更可）。最小化もできます
- 選択中のペンをもう一度タップすると、太さ・不透明度・筆圧などの詳細設定が開きます
- 定規: ペンを定規の縁に近づけると、まっすぐな線になります（つまみで移動・回転、45°刻みでスナップ）
- 投げ縄: 囲んだ書き込みを移動・削除・複製・色変更
- ページ移動の履歴: 右の列の ← → で、ジャンプする前のページへ戻る・進む

## v11: アニメーションと機能
- 動き: 画面を開いたときの段階的な登場（ホームのタイル・一覧・ツールカード・ツールバー）、ページ描画のフェードイン、タップの波紋、ツールバーを離した位置からばねで吸い付く移動、ビュー遷移、ダイアログ背景のフェード。設定の「画面の動き」で 標準／控えめ／オフ
- 長押しで図形補正: 線を引いて止めると、直線・円（楕円）・四角に整います
- 速度で細く: ペンの詳細設定に追加（速く動かすほど細くなる）
- 現在のページのクイック編集: 右/左回転・複製・前後に白紙を挿入・削除（「編集」メニュー）
- 全ファイル横断の本文検索: ホームの「検索」で、保存済みの全PDFの本文から探せます

## v12: ツールバーとペンの修正
- ページ移動のスライダーを廃止。上部バーは下へスクロールすると隠れ、スクロールでは戻りません（画面の上端、または上の小さなタブをタップで再表示）
- ツールバー: 画面のどこにでも自由に置けます（端の近くで離すとスナップ）。つまみ・背景をドラッグすると、ばねのように追従して傾き、離すと弾んで止まります。最小化は、右上の「−」、つまみのタップ、「…」メニューのどれでも可能。最小化後の丸いボタンも自由に動かせます
- ペン: 不透明度100%でも透ける不具合（画面全体の乗算ブレンド・鉛筆の自動減光）を修正。ペン・ボールペン・鉛筆は、それぞれ色・太さ・不透明度を別々に記憶。ペン先とバンドのイラストが、その色になります。蛍光ペンの色が他のペンに移らないように修正。図形も独立した色・太さ

## v13: 形が変わるツールバー・新ツール
- 形の変化: 下・上の端では横長、左・右の端では縦長に、角（四隅）に近づけると、ペンのアイコンだけの小さな丸になります。ドラッグ中も、位置に応じて途中で形が変わります。形と各ボタンは、ばねのようなアニメーションで滑らかにつながります。
- 小さな丸をタップすると元の大きさに戻り、ドラッグすると引き出せます。「−」ボタンは角へ縮めます。
- ペンの種類に マーカー・筆 を追加（不透明度100%の不透明な線）
- 消しゴム: 「線ごと消す」「部分的に消す」を選べます。速いなぞりでも、間を補間して確実に消えます
- 図形に ひし形・星 を追加
- レーザーポインタ: 指やペンの軌跡が光って、約1秒でフェードアウトします（書き込みは残りません）
- 範囲を切り取り: 囲んだ範囲を画像として共有、または書き込み内にそのまま貼り付け
- 付箋の色を選べます（6色）
- 絵文字スタンプ（✅ ❌ ⭐ など10種類）

## v14: 形の変化をなめらかに
- 形（幅と高さ）はばねの物理計算で動きます。途中で形が切り替わっても速さが連続するので、飛んだり引っかかったりしません。縮むとき（丸になるとき）は、少し速いばねを使います
- 掴んだ位置は、縦横の切り替えで瞬時に動かさず、少しずつ移動します
- 中身（ボタン）は、形の変化に合わせて滑らかにスライドします。丸になるときは、中身がすっと消え、丸のペンアイコンが現れます
- 丸の上では、隠れている中身にはタップが届きません（丸だけに反応します）

## v14b: ツールバーの動きの調整
- ドラッグ中は傾けず、指に遅れて滑らかについてきます（時間に基づく追従）
- 形の変化の途中で高さが跳ねないよう、ドッキング時の余白と間隔を統一しました
- つまみはアイコンより前面に出し、つまみで必ず掴めるようにしました

## v15: ツールバーの持ち手と動き
- 縦型（左右の端）のとき、持ち手は上ではなく、内側の縁の中央に出ます
- 形が変わる途中でも、画面からはみ出さないように位置を保ちます（描画された実際の位置で確認）
- ツールは、選んでいないものが少し引いて見え、選んだものが浮き上がります。色は選んだ色に合わせて、なめらかに変わります
- 丸のペンアイコンは、道具を変えると、ばねのように跳ねて入れ替わります
- 色の丸は、選ぶと少し大きくなります。背景は、いま選んでいる色に少しだけ染まります

## 補足
- アイコンはGoogle FontsのMaterial Symbols（Rounded）を読み込みます。初回はオンラインで開いてください。
- 更新を確実に配信するときは sw.js の `V`（キャッシュ名）を変更してください。
- PDF描画ライブラリ(pdf.js / pdf-lib)はcdnjsから読み込み、初回以降はService Workerがキャッシュします。
- 書き込みと開いたファイルは端末内(IndexedDB)に保存されます。
